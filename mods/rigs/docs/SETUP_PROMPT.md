# Set up Rigs with your agent

Use **+ → Agent Setup Prompt** in the Rigs panel for a short prompt pointing to this installation’s agent guide. Paste it into the agent you already use. No profile JSON is needed beforehand.

The copied prompt points to the installed AGENTS.md, which contains the exact CLI paths and setup rules. The reusable text below needs your installation’s guide path.

```text
Read and follow "/absolute/path/to/rigs/AGENTS.md" to set up a Herdr rig for my current project.
```
